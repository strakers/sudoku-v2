# SUDOKU-JS

A sudoku project I built using JavaScript and math as a challenge to myself.


## Links

## About

I initially built v1 using vanilla JS for fun, and so that my mom could play sudoku online. Years later, I came back to
build v2 using more modern JS. This project has always been a fun way for me to test my skills and push the bar in a
creative way. It also helps me learn more through practical application.
